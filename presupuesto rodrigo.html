1. Resumen Ejecutivo

El objetivo del proyecto es proveer e implementar un sistema web intuitivo, ágil y de alta accesibilidad visual, diseñado específicamente para facilitar la operación diaria de un almacén. La interfaz prioriza la simplicidad de uso mediante botones prominentes, tipografías legibles de alto contraste y procesos directos para el registro de ventas y carga de stock.

2. Alcance del Sistema (Módulos Incluidos)

Módulo 1: POS "Senior Friendly"

  • Buscador Mixto: Campo único para lectura de código de barras o ingreso por nombre.
  • Productos Pesables: Soporte para ingreso de cantidades decimales (kilos/gramos).
  • Selección de Pago: Botones gigantes de alto contraste (EFECTIVO / TRANSFERENCIA).
  • Venta Rápida: Registro directo sin requerir impresión obligatoria.

Módulo 2: Alerta Mercado Pago

  • Integración Webhook: Conexión con la API oficial de Mercado Pago.
  • Alerta en Pantalla: Cartel automático al acreditarse transferencias en el QR Fijo.
  • Aviso Sonoro/Visual: Confirmación en tiempo real sin consultar el celular.
  • Historial MP: Registro diario simplificado de acreditaciones.

Módulo 3: Stock y Precios

  • Catálogo Visually Clear: Listado claro de productos en alta.
  • Edición Ágil: Alta de artículos, vinculación de códigos de barras y precios.
  • Actualización de Precios: Modificación rápida de precios de venta al público.
  • Control de Existencias: Descuento automático de stock tras venta.

Módulo 4: Seguridad y Acceso

  • Control de Usuarios: Pantalla de inicio de sesión (Login) resguardada.
  • Seguridad de Datos: Protección de la información del comercio.
  • Acceso Cloud: Disponible desde cualquier navegador web.

3. Alcance Excluido

Atención - Funcionalidades fuera de la versión base:

  • Facturación electrónica (AFIP / Comprobantes fiscales).
  • Módulo de gestión de costos, márgenes de ganancia y proveedores.
  • Integración directa por cable con balanzas electrónicas (los pesos se ingresan manualmente).

4. Modalidad de Servicio y Mantenimiento (SaaS)

El sistema se ofrece bajo la modalidad de Servicio Mensual Todo Incluido, lo que garantiza el funcionamiento continuo y soporte directo sin requerir una inversión inicial de desarrollo.

Componente Descripción del Servicio Incluido
Infraestructura Cloud Alojamiento en VPS de alta disponibilidad y copias de seguridad de la base de datos.
Seguridad & SSL Subdominio configurado con certificado SSL (HTTPS) obligatorio para la API de Mercado Pago.
Soporte Técnico Mantenimiento preventivo, resolución de incidencias y asistencia directa ante dudas.

6. Cláusula de Ajuste Tarifario

Actualización de Servicio: El valor del abono mensual se actualizará de forma trimestral aplicando la variación porcentual del Índice de Precios al Consumidor (IPC) publicado por el INDEC acumulado en dicho período, a fin de mantener el equilibrio económico del servicio y los costos de infraestructura en servidores. Cada actualización será notificada al cliente con al menos 10 días de anticipación a la emisión del próximo pago.
